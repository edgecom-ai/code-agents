# Agents

Agent configuration for Edgecom frontend repos.

- [`agent-kit/`](agent-kit/README.md) — the portable rulebook, skills, and
  enforcement hooks, extracted from the panel project.
- [`agent-kit/reference/stack.md`](agent-kit/reference/stack.md) — the
  framework selections the kit assumes (pnpm, Turborepo, TypeScript, React on
  Vite, TanStack, Tailwind, and the rest), as settled in the panel project.
